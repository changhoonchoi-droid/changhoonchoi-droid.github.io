① 네이버 블로그 — 주식투자 (andichoi)

진단

  • 양이 신뢰를 깎고 있습니다. 네이버는 블로그를 '한 사람이 꾸준히 깊게 쓰는 곳'인지(C-Rank)와 글 하나가 질문에 잘 답하는지(D.I.A.)로 평가합니다. 하루 20~30편이 기계적으로 올라오면 글마다 검색 순위가 낮게 잡히고, 아주 구체적인 제목으로 찾아도 첫 페이지에 거의 나오지 않습니다.
  • 카테고리가 45개로 흩어져 있습니다. 업종별 카테고리 대부분이 몇 편뿐이라 '이 블로그는 무엇을 잘 쓰는 곳인가'가 흐려집니다.
  • 매일 같은 제목의 퀀트 리포트가 쌓입니다 (뽑힌 종목이 그대로면 제목·내용이 거의 같음) — 네이버가 '유사 문서'로 묶어 노출을 줄이는 대표적인 경우입니다.
  • 방문이 새 글에 기대고 있습니다. 발행이 멈춘 11/05 방문자가 절반으로 떨어졌습니다. 검색으로 꾸준히 들어오는 '오래 읽히는 글'이 적다는 뜻입니다.
  • 직접 쓴 글('투자에 대한 생각'·'주식농부 기업 Study')이 10월 이후 거의 없습니다. 네이버 AI 브리핑 5원칙의 첫째가 '직접 경험한 지식'입니다.

성장 방안

  1. 하루 발행을 8~12편으로 줄이고 글마다 깊이를 더합니다. 줄이는 순서: 자동 기업분석(낮 8회+밤 9회) → 퀀트 리포트(순위가 바뀐 날만) → 45채널 묶음(하루 3 → 1). 자동 설정
  2. 퀀트 리포트는 '바뀐 것'이 제목이 되게 — 새로 들어온 종목·빠진 종목이 없으면 그날은 쓰지 않고, 주 1회 '이번 주 순위 변화'로 묶습니다. 자동 설정
  3. 카테고리를 8개 안팎으로 합칩니다 — 예: 기업분석(업종은 태그로) · 리포트 요약 · 퀀트 · 투자관련 뉴스 · 연금 이야기 · 투자에 대한 생각 · 주식농부 Study · 행복취미. 업종 카테고리 글은 옮기고 태그로 남깁니다. 사용자 승인
  4. 제목을 '사람이 검색하는 말'로 — '종목명 + 궁금한 점'(예: "코나아이 배당 계속 줄까, 3분기 실적으로 본 답")처럼 종목명을 앞에, 숫자·물음을 넣고 대괄호 머리([퀀트 전략 리포트 11/06])는 뒤로 뺍니다. 자동 설정
  5. 일주일에 1~2편은 직접 쓴 글 — 실제 매매·생각·실패담 몇 줄만 텔레그램으로 보내 주시면 블로그 글쓰기 봇이 정리합니다. 자동 글이 줄 수 없는 '경험'이 블로그 전체 신뢰를 올립니다. 사용자
  6. 모아 보기 글(허브 글)을 만듭니다 — '반도체 기업 분석 모음', '연금 계좌별 정리' 처럼 기존 글을 묶어 링크하는 글을 업종·주제마다 하나씩 두고 새 글이 생기면 갱신합니다. 자동 설정
  7. 네이버 서치어드바이저에서 블로그 RSS 를 제출하고 '수집 현황'을 주 1회 봅니다. 이웃(같은 주제 블로그)과 댓글·공감 교류도 C-Rank 에 도움이 됩니다. 사용자

진단

  • 유튜브 25~32편을 한 글에 몰아 담은 묶음 글이 10만 자를 넘습니다. 구글·다음은 '한 글 = 한 주제'를 좋아하고, 너무 긴 글은 끝까지 읽히지 않아 체류 신호도 나빠집니다. 검색어 하나에 딱 맞는 글이 되지 못합니다.
  • 은퇴 후 이야기에서 거의 같은 제목이 이틀 사이 2~3편 나왔습니다 (퇴직연금 사외적립 의무화, 국민연금 리밸런싱). 같은 소식을 반복하면 중복 문서로 묶입니다.
  • 개인정보처리방침이 없으면 애드센스 심사에서 막히거나 광고가 제한될 수 있고, ads.txt 가 없으면 광고 수익 일부가 빠질 수 있습니다.

성장 방안

  1. 묶음 글을 주제별 글로 쪼갭니다 — 25편짜리 한 글 대신 '반도체', '부동산', '연금'처럼 주제가 같은 영상 3~5편씩 묶어 2,500~4,000자 글 몇 편으로. 하루 공개 15편 한도 안에서 운영합니다. 자동 설정
  2. 노후연금 중복 막기 — 최근 7일 안에 같은 제도·소식을 다룬 글이 있으면 새 글을 쓰지 않고 기존 글에 '업데이트' 문단을 더합니다. 자동 설정
  3. 개인정보처리방침 페이지를 만들고(관리 → 콘텐츠 → 페이지), 애드센스 연동 화면에서 ads.txt 를 확인합니다. 사용자 (초안은 만들어 드림)
  4. '은퇴 후 이야기'를 이 블로그의 간판으로 — 국민연금·IRP·ISA·주택연금처럼 오래 검색되는 주제라 시간이 지날수록 방문이 쌓입니다. 계좌별 '총정리' 글을 하나씩 두고 새 소식이 생기면 그 글을 고칩니다. 자동 설정
  5. 구글 서치 콘솔·다음 웹마스터도구에서 사이트맵 제출과 '색인 생성' 상태를 확인합니다. 사용자

진단

  • 구글에서 거의 찾아지지 않습니다. 새 블로그는 구글이 믿기까지 몇 달이 걸리는데, 그 사이 같은 형식의 자동 글이 하루 9~10편 올라오면 구글의 '대량 생산 콘텐츠' 기준에 걸릴 위험이 커집니다.
  • 절반이 '오늘의 트렌드'(사회·이슈)입니다. 뉴스·화제 글은 하루 이틀이면 검색이 끝나고, 언론사·포털이 위에 있어 새 블로그가 이기기 어렵습니다.
  • 반대로 '연령별 생각하는 질문'(교육)과 IT 원리·따라하기는 몇 달 동안 검색되는 주제입니다. 애드센스 단가도 교육·IT 가 사회 이슈보다 높은 편입니다.

성장 방안

  1. 트렌드 글을 하루 3편 → 1편(저녁 정리)으로 줄이고, 비운 자리를 교육·IT '오래 읽히는 글'로 채웁니다. 자동 설정
  2. 교육 글은 검색어형 제목 — "달은 왜 매일 모양이 바뀔까? 아이에게 설명하는 법 (5~7세·초등)"처럼 부모가 실제로 치는 말과 연령을 제목에. 질문마다 따로 찾아오도록 목차·FAQ 를 붙입니다. 자동 설정
  3. 라벨 페이지를 메뉴로 쓰고, 글 끝 '함께 읽으면 좋은 글'을 같은 라벨 안에서 3편씩 연결해 한 번 온 사람이 더 읽게 합니다. 자동 설정
  4. 구글 서치 콘솔에서 '페이지 색인 생성' 보고서를 확인합니다 — 색인되지 않은 글이 많으면 발행 수를 더 줄입니다. 사용자
